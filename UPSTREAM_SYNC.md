# Проверка синхронизации с LuCI Mobile

Ветка: `codex/sync-upstream-2`. База Studio: `efdb301`; оригинал: `cogwheel0/luci-mobile` через `81ebcfe` (релиз 2.0.0 и последующие исправления входа/обновления клиентов). Версия кандидата: 2.5.25+4525.

Новая навигация: Дашборд / Сеть / Клиенты / Мониторинг / Настройки. В Настройках пункт **OpenWrt Studio** открывает ForkOP, VPN, Mihomo, watchdog, USB и остальные инструменты форка. **Оформление Studio** сохраняет выбор цветов и масштаба. Простой режим и переход в экспертный остаются доступными. Диагностика оригинала и расширенная диагностика Studio сохранены отдельно.

## Локально

При наличии локальных правок сначала сохраните их отдельным коммитом или stash. Затем в клоне мобильного репозитория:

```sh
git fetch origin
git switch --track origin/codex/sync-upstream-2
flutter pub get
flutter analyze --fatal-infos
flutter test
flutter devices
flutter run -d ID_ТЕЛЕФОНА
```

Если ветка уже существует: `git switch codex/sync-upstream-2` и `git pull --ff-only`. Нужны Flutter 3.47.7, Android SDK/JDK 21 и включённая USB-отладка телефона. Телефон и роутер не нужны для компиляции; они нужны для аппаратной проверки. Linux собирается по [LINUX_INSTALL.md](LINUX_INSTALL.md).

## Проверка на своём роутере

Перед изменениями запишите выбранный VPN и настройки, которые собираетесь менять.

- Вход в роутер: загрузка завершается, повторный вход и смена роутера не показывают данные предыдущего устройства.
- Простой и экспертный режимы: список ForkOP содержит реальные авто-группы; выбранная политика, конечный узел и задержки соответствуют панели роутера. Переключение подтверждается состоянием роутера; отказ команды показывает ошибку.
- В Настройках доступны инструменты Studio, цвета/масштаб и новые системные настройки/службы оригинала.
- Клиенты: открывается детальная страница, есть список онлайн/офлайн и раскрытие карточки. Запись настроек клиента другого роутера не допускается.
- Новые операции Wi-Fi/межсетевого экрана сначала проверяйте на тестовой конфигурации. Сообщение о подтверждении/откате должно соответствовать правам rpcd.
- Watchdog останавливается при выходе и смене сессии. Фоновые уведомления оригинала включаются отдельно, добровольно.

После проверки восстановите исходный VPN и изменённые настройки. Результаты аппаратной проверки 19 октября 2026 и оставшиеся ограничения описаны в [HARDWARE_VALIDATION.md](HARDWARE_VALIDATION.md); автоматические тесты её не заменяют.

Тестовый APK из workflow **Validate upstream sync** имеет отдельный applicationId `com.cogwheel.LuCIMobile.upstreamtest` и debug-подпись. Он устанавливается рядом со стабильной версией; сохранённые роутеры и пароли стабильного приложения в него не переносятся. Это сборка для локальной проверки, не APK для обновления стабильного выпуска. Введите подключение к роутеру вручную. На USB-телефоне:

```sh
adb install -r OpenWrtStudio-2.5.25-upstream-test-arm64.apk
```

APK предназначен для ARM64. Для других архитектур соберите локально `flutter build apk --debug`.
